# Evidence and confidence

- `EXTRACTED`: directly present in supplied material or authoritative page.
- `INFERRED`: transparent conclusion derived from extracted facts.
- `UNVERIFIED`: inaccessible, ambiguous, stale, hearsay, or unconfirmed.

Useful frontmatter fields: `source`, `last_verified`, `scope`, `status`. Repetition does not upgrade an unverified claim; for disagreement, list each source and date.
