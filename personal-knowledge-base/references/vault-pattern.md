# Minimal Markdown/Obsidian pattern

Use plain Markdown, YAML frontmatter, relative wiki-links, and stable filenames. Keep originals in place and link to them.

```yaml
---
title: "Source title"
source_type: pdf
source_path: "/path/to/original.pdf"
captured_at: 2026-09-05
confidence: EXTRACTED
status: current
---
```

Topic pages can use sections: `摘要`, `关键事实`, `行动与截止日期`, `适用范围`, `冲突与待核实`, `来源`.
